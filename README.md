# iCertify — Portal UI

Front-end interface for **iCertify**, a building certification portal used by Project Building Certifiers (PBC). Covers project tracking, inspections, communications, documents, and client portal access across NT, SA, and VIC jurisdictions.

Built with [Lovable](https://lovable.dev) · React 19 · TypeScript · TanStack Router · Tailwind CSS v4

---

## Local Setup

### Prerequisites

| Tool | Version | Download |
|------|---------|----------|
| Node.js | 18 LTS or higher | [nodejs.org](https://nodejs.org) |
| npm | Included with Node.js | — |
| Bun *(optional, faster)* | Latest | [bun.sh](https://bun.sh) |

### 1. Clone the repository

```bash
git clone <your-github-repo-url>
cd harmony-kit-ui-main
```

### 2. Install dependencies

```bash
npm install
```

Or with Bun:

```bash
bun install
```

### 3. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. The server reloads automatically on file save.

## Pages & Routes

### Authentication (uses `AuthLayout`)

| Route | Page | Notes |
|-------|------|-------|
| `/` | Sign In | Email + password login. Links to forgot password. |
| `/forgot-password` | Forgot Password | Sends a reset link to the user's email. Links expire after 60 min. |
| `/set-password` | Set Password | Used for new account activation and password reset. Enforces 12+ chars, letter, number. |
| `/link-expired` | Link Expired | Shown when an invitation or reset link is no longer valid. |

### Main Application (uses `AppShell`)

| Route | Page | Notes |
|-------|------|-------|
| `/projects` | Projects List | Paginated project table. Toggle Active (42) / All (387). Columns: project #, address, status, client, services, next inspection, last activity, allocated staff. |
| `/projects/:projectId` | Project Detail | Full project workspace — see tabs below. |
| `/contacts` | Contacts | Master directory. Tabs: Clients · Companies · Staff · All portal users. Search and portal-status filters. |
| `/404` | Not Found | Catch-all for unknown routes. |

### Project Detail Tabs (`/projects/:projectId`)

| Tab | Content |
|-----|---------|
| Overview | Project summary, status, key dates, open alerts |
| Services | Certification and consulting services list |
| Milestones | Stage progress and milestone tracking |
| Inspections | Scheduled and completed inspections |
| Communications | Email, SMS, phone call logs, in-app messages |
| Documents | Certificates, uploaded files, drawings, e-signed forms |
| File Notes | Internal working journal (staff only) |
| Tasks | Open to-do items |
| Contacts | Project-level stakeholders — client side, design team, authorities |
| Activity | Immutable system audit log |
| Accounts | Fee offers, invoices, payments — Xero read-only sync |

## Deploy

### Production build

```bash
npm run build
```

Output goes to `dist/` — plain HTML, CSS, and JS ready for any static host.

### Vercel (recommended)

```bash
npm install -g vercel
vercel
```

Or connect the GitHub repo in the Vercel dashboard — it auto-detects Vite and deploys on every push.

### Netlify

Drag and drop the `dist/` folder at [app.netlify.com](https://app.netlify.com), or connect the GitHub repo for CI/CD.

### Manual / cPanel

Upload the contents of `dist/` to your `public_html` directory via FTP or the hosting file manager.

## Notes

- `routeTree.gen.ts` is auto-generated by TanStack Router on `npm run dev` — never edit it manually.
- The logo is imported directly from `src/assets/pbc-logo.svg` — not from Lovable's CDN — so it works in all environments.
- All Radix UI components live in `src/components/ui/` and are unstyled primitives wrapped with Tailwind classes.
